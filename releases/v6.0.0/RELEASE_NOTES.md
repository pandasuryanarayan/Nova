## What's New in v6.0.0
- **Chrome-Style Centric Home Identity**: Large centered Nova Browser app icon badge above a prominent, bold `Nova Browser` title (`32.sp`) and instant middle search/URL omnibox bar.
- **Minimal Home Bottom Bar**: On the Home screen (when no website is open), the bottom bar hides the Back button, Home button, and duplicate bottom search bar — keeping only the **Tab Switcher (`[N]`)** and **3-Dot Menu** buttons.
- **On-Demand Dual Bars with Smooth Left-to-Right Slide Animation**:
  - Entering a search or URL in the middle Home search bar automatically reveals the **Top Website Bar** (Lock icon, Website Title, 1-Tap Bookmark button, and Fall-Down Link drawer) and slides in the **Bottom Website Controls** (`Left Arrow`, `Home`, `Inspect`, `Video Detector`, `Refresh`) with a smooth **Left-to-Right** slide animation.
  - Returning to the Home page smoothly reverses the animation (**Right-to-Left** slide out).
- **Unified Bookmarks Manager Icon**: The 3-Dot menu now uses the stacked `Bookmarks` manager icon matching the Home screen Bookmarks Manager button.
- **Full R8 Minification & Resource Shrinking**: Reduced signed release APK size to `2.36 MB` (`2,475,080 bytes`), optimized for fast startup and 60fps scrolling on budget Android devices.
